# 有利可圖的真相｜三位老師版

繁體中文的虛構黑色諷刺選擇遊戲。扮演調查委員，依序處理三位老師的案件。不當選擇可增加虛構收入，結案呈現每位老師承受的代價。

## 案件與玩法

1. 第一位A老師：學生未達獎勵標準後提出不實性平指控。3 次選擇：獎勵規則、完整報告、最後認定。
2. 第二位B老師：學生偷偷戳老師的屁股，老師擋開手並立即停止。1 次選擇：本案中的正當防衛，或忽略完整情境認定為體罰。
3. 第三位C老師：學生的證詞對老師有利。1 次選擇：忠實保留原話，或誘導改口為不利說法。

共 5 次選擇，32 種路線。畫面只顯示「委員累積收入（虛構）」數值；老師的情況以文字與個別結案呈現。收入累計，但各案結果獨立。支援重玩、完整紀錄與文字下載。

角色、案情、報酬制度均為虛構。不代表真實性平案件或委員收費制度，不暗示申訴者普遍提出不實申訴。第二案的分類是本案設定中的遊戲判斷，不是對現實案件的法律認定。作品諷刺不當誘因、選擇性採證與誘導證詞。

## 大地圖與移動

遊戲從假想的霧川鎮大地圖開始。點選金色學校節點，委員會沿道路移動，抵達後點「進入學校開會」。

- 青禾學校：A老師，3 次選擇。
- 河畔學校：B老師，1 次選擇。
- 松丘學校：C老師，1 次選擇。

每位老師的會議結束後，必須返回大地圖並移動到下一校。完成三校後也返回地圖，再查看結案總結。校際移動不影響收入，已完成的學校不能重複領取獎金。重新調查會重置位置與進度。

地名、道路、學校均為假想。地圖為內嵌 SVG 與 HTML 按鈕，支援鍵盤操作；減少動態偏好會關閉移動動畫。

## 會議室場景

內嵌 SVG／CSS 場景包含長桌、委員、空的當事人座椅、百葉窗、日光燈、文件與信封。隨不當選擇累積，場景逐漸染上暗紅色。無額外圖片或外部資源。

## 本機遊玩

直接用瀏覽器開啟 `index.html`。無套件、無建置、無帳號、無資料上傳。重新整理會重置進度。

## 放上 GitHub Pages

1. 在 GitHub 建立儲存庫，例如 `unfair-hearing`。
2. 將本資料夾內的 `index.html`、`README.md` 與 `.nojekyll` 上傳至儲存庫根目錄並提交。
3. 進入儲存庫 **Settings → Pages**，選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/(root)`，儲存。
5. 等候部署完成後，從 Pages 頁面開啟網站。常見網址為 `https://你的帳號.github.io/unfair-hearing/`。

若已部署前版，替換根目錄的 `index.html` 即可更新遊戲，可一起更新 README。此交付尚未替你建立 GitHub 儲存庫或部署。

## 修改

畫面、樣式與邏輯都在 `index.html`。`teachers` 設定老師，`cases` 設定情節與選項，`outcome()` 產生各案結果。遊戲每案資料獨立記錄，進度依選項數計算。
