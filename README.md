# 校事委員的一天 V1.6

**委員出得去，投訴進得來，校事會議發大財!**

以校事會議新聞爭議為靈感的虛構諷刺桌遊。HTML、CSS、JavaScript 全部內嵌於 `index.html`，無框架、無套件、無外部字型圖片，不需建置。桌面與手機皆有對應排版。暱稱儲存在本機瀏覽器，不會傳送出去；遊戲進度只保留在當次頁面記憶體，重新整理會重置進度。若瀏覽器停用本機儲存，仍可在目前頁面保留暱稱。

## 立即遊玩

解壓縮後，用 Chrome、Edge、Firefox 或 Safari 開啟 `index.html`。電腦可直接雙擊檔案，不需啟動伺服器。手機建議使用 GitHub Pages 網址。

## 放上 GitHub Pages

1. 在 GitHub 建立一個 repository，例如 `school-committee-game`。使用支援 Pages 的帳號／方案；免費使用可建立 public repository。
2. 點 **Add file → Upload files**，將解壓縮後的 `index.html` 上傳到 repository 的最上層，並 **Commit changes**。`README.md`、`test.cjs` 可一起上傳；ZIP 本身不會直接變成網站。
3. 打開 **Settings → Pages**。
4. 在 **Build and deployment** 中，Source 選 **Deploy from a branch**。
5. Branch 選 **main**，資料夾選 **/(root)**，按 **Save**。若你使用其他分支，選擇實際放置 `index.html` 的分支。
6. 等 GitHub 完成部署。Pages 設定畫面會顯示實際網址，通常是 `https://你的帳號.github.io/school-committee-game/`。
7. 後續更改 `index.html` 並提交，GitHub Pages 會重新發布。沒有 API 金鑰、後端或環境變數。

若已有 Git repository，也可將檔案複製到該 repository 根目錄後自行 commit/push。這份交付未連接或修改任何 GitHub 帳號。

GitHub 官方說明：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 遊戲規則

- 縣市為虛構「消失縣」。十間學校與十位教師的名稱及身分都是虛構；教師只以姓氏加「OO」呈現；順時針固定路線，星期一到五每天兩校（上午、下午）。大富翁式棋盤呈現，不以骰子跳過案件。
- 在遊戲封面輸入綽號，最多 12 字；空白或只有空格不能開始遊戲。綽號會出現在狀態列、劇情、電話與結算。
- 初始金錢 0 元，良心 100。每個壞心選擇基本收入 **3,000 元**、良心減少 **10**。全部切詞挑戰通過時，十次共 **30,000 元**，良心 **0**；挑戰失敗會降低下一場收入。
- 每間學校有不同的行政失靈指數：70、100、45、85、0、95、60、80、30、55。
- 被阻止機率 = `100% − 行政失靈指數`。每校獨立抽取一次 `Math.random()`；0 必定阻止，100 不會阻止，70 為 30% 阻止機率。
- 若不當選擇被阻止，主要傷害未發生，但捲入調查造成 **5 點痛苦**。未被阻止，依案件設定增加 **60–94 點**。這些是虛構指標。
- 為滿足固定五天獎勵與諷刺設定，壞心路線即使被擋下，仍領取虛構出席報酬；意圖已形成，良心照扣。此金額及機制不代表真實校事會議收費或獎酬。
- 選擇「選擇良心」並通過切詞挑戰後，會接到虛構同行「金算盤委員」的勸說來電。來電可選「繼續行程」，回到同一學校的案卷；或選「堅守良心，跳到結算」，保留目前金額與良心並結束。來電選擇本身不計分、不增加教師痛苦。
- 星期四出發前，先前三天中未被阻止、痛苦達 70 的案件，進入失業的虛構加速劇情，痛苦再加 5（最高 100）。此處可選良心，通過切詞挑戰後接聽電話；失敗則前往星期四上午的學校。選擇繼續賺錢也會有切詞挑戰，但不加錢、不扣良心；挑戰失敗影響下一場收入。
- 結算永遠列出全部十位教師。未到訪為 0 點痛苦；秉公處理與被阻止會分別標示。
- 結算下方列出三則新聞與四則新增新聞或評論資料，皆另開新分頁。

按「再玩一次」會直接沿用上一局暱稱開始新局，不再要求輸入。重新整理或重新開啟網頁時，報到畫面也會預填已儲存的暱稱。

## V1.4 切詞挑戰

- 每局 20 秒、5 波，每波 4 個詞；從指定詞語庫隨機抽取 10 個有利詞及 10 個不利詞，重複詞彙去重。
- 賺錢選擇：切掉「有利老師」的詞。良心選擇：切掉「不利老師」的詞。
- 通過條件：切對至少 6 個，誤切不超過 2 個。可按住滑鼠拖曳、手指滑動、點按，或以 Tab 選詞及 Enter 切下。
- 賺錢挑戰失敗：本場照常入帳，下一場基本收入減少 1,500 元，只影響一場且不疊加。最後一場失敗時，因沒有下一場而不追扣。行政把關在切詞前抽取一次；把關成功直接跳過切詞，不新增減薪。前場已產生的減薪仍套用本場收入。
- 良心挑戰失敗：本場不加收入、不扣良心、不增加痛苦，必須前往下一校；最後一校失敗則按行程結束結算，不算良心結局。
- 切換分頁會暫停；Esc 或放棄按鈕視為未通過。支援系統減少動態設定，詞卡保持靜止但仍分波更新。
- 移除地圖中央原本的虛構提示句；封面、暱稱保留、同行電話雙選項與新聞連結沿用。

## 改文字與數值

使用文字編輯器開啟 `index.html`：

- `SCHOOLS`：十校名稱、教師、案情、有利資料、壞心選項、行政阻止劇情、失業故事、失靈率及痛苦值。
- `WORD_BANK`、`SLICE_RULES`：詞語庫、時間、過關門檻及收入減少金額。
- `applyBad`：每次獎勵、良心扣分、隨機阻止邏輯。
- `advance`：第四天事件與終局時點。
- `SOURCES`：原始資料連結與簡短摘要。
- 頁首 `<style>`：色彩、棋盤與手機排版。

修改報酬或扣分時，也請同步更新遊戲文字、說明與測試的預期值。

## 檢查

若電腦已安裝 Node.js，可執行：

```sh
node test.cjs
```

測試包含 1,024 種完整行程的隨機極端組合、十個學校時點的良心結局、第四天良心結局、0／70／100 的阻止率邊界、重複點擊防護、綽號轉義，以及 UI 渲染與事件的基本檢查。另測試切詞門檻、滑動命中、分波動畫、倒數暫停、放棄、下一場收入扣減及良心失敗分支。DOM 測試採輕量替身，**不是瀏覽器排版、視覺或實機測試**。

建議上線後以桌面及手機確認：開始 → 選擇壞心 → 每校結果 → 第四天事件 → 週五結算；再玩一次 → 良心 → 電話 → 提早結算。測試新聞連結是否另開分頁。

## 載入效能
